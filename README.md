# StuduntHub

A web app for students to organize their courses, tasks, grades and focus time.

🔗 **[Live demo](https://kenzabertoul.github.io/StudentHub/)**

## Features
- Task manager with priorities and deadlines
- Course tracking with credits and weighted average
- Grade target calculator
- Focus timer (25-minute sessions)
- Notes, dark mode, and a demo mode to explore quickly

## Tech
HTML, CSS and JavaScript. Data is stored locally in your browser (localStorage), with no account and no backend.
